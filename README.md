Space Warriors Onlineリアルタイムで通信し、協力・競い合いながら宇宙の敵を撃破するマルチプレイヤー・シューティングゲームです。🚀 特徴リアルタイム・マルチプレイ: Socket.ioを使用し、複数のプレイヤーと同じ画面で遊べます。慣性移動システム: 自機に物理挙動（加速・摩擦）を取り入れ、滑らかな操作感を実現。パワーアップアイテム: 敵を倒すと出現するアイテムで「3-WAYショット」や「バリア」を装備可能。巨大ボスバトル: スコアが一定数（3,000点）に達すると、強力な攻撃を仕掛けるボスが登場。🛠 使用技術フロントエンド: HTML5 Canvas, JavaScript (Vanilla JS)バックエンド: Node.js, Express通信: Socket.io (WebSocket)📦 セットアップと実行方法リポジトリをクローンまたはダウンロード依存関係のインストールBashnpm install
